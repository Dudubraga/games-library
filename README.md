# 🎮 4Teto Games Library

Uma biblioteca de jogos compartilhada em tempo real, feita para grupos de amigos organizarem o que jogam e o que querem jogar juntos.

---

## ✨ Funcionalidades

- **Biblioteca compartilhada** — alterações aparecem em tempo real para todos
- **Adicionar e editar jogos** — título, plataforma, categorias e capa
- **Status por jogo** — separe o que vocês já têm (✅) do que querem jogar (📅)
- **Filtros** — por plataforma, status e categoria
- **Ordenação** — alfabética, por status ou por plataforma
- **Busca** — encontre qualquer jogo pelo nome
- **🎲 Aleatório** — sorteia um jogo da biblioteca (filtrando por status)
- **🎡 Roleta** — selecione os jogos candidatos e gire a roleta animada
- **📥 Importar em lote** — adicione vários jogos de uma vez via JSON

---

## 🛠️ Stack

| Tecnologia | Uso |
|---|---|
| [React 18](https://react.dev/) + [Vite](https://vitejs.dev/) | Frontend |
| [Firebase Firestore](https://firebase.google.com/docs/firestore) | Banco de dados em tempo real |
| CSS customizado | Estilização (sem frameworks) |
| [Vercel](https://vercel.com/) | Deploy |
